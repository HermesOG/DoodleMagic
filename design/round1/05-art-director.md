# 05. Арт-директор: красиво без 3D-моделей (раунд 1)

**Суть.** Предлагаю стиль **«Тушь и свет»**: мир нарисован монохромной тушью на рисовой бумаге, цвет в кадре есть только у магии. Техника как в Doodle District (G-buffer плюс один пост-пасс), но своя идентичность: кисть и размывка вместо ручки и штриховки. Маги собраны из плаща, маски и парящих рук, без ног и скелета.

---

## 1. Три визуальных направления

| | **A. Тушь и свет** (рекомендую) | **B. Неон-руны** | **C. Пастельный low-poly** |
|---|---|---|---|
| Картинка | Сумиэ: кисть, размывка, туман, пустота бумаги. Магия — единственный цвет, светится | Тёмный индиго-мир, геометрия почти чёрная, рёбра и руны светятся тонкими линиями | Плоские цвета, 2–3 тона cel-шейдинга, цветные контуры, градиентное небо |
| Референсы | Okami, MadWorld (монохром + акцент), Pentiment, китайская живопись шань-шуй | Rez, Tron, Hyper Light Drifter, Ghostrunner | Superhot, Firewatch, Sable, Townscaper |
| Техника | G-buffer (тон, id материала, нормаль) → пост-пасс: контур переменной толщины, 3 тона размывки с «растёканием» краёв по шуму, волокна бумаги, туман к цвету бумаги. Магия рисуется в отдельный HDR-буфер и подмешивается с bloom | Контур по глубине и нормалям пишется как свет, плюс bloom и сильный туман | Стандартный toon-шейдер со ступенчатым освещением, контур обратными нормалями или в посте |
| Плюс для магии | Максимальный контраст: магия — единственное насыщенное пятно. «Магия раскрашивает мир» | Свечение эффектное с первой секунды | Тёплый дружелюбный вид, проще всего для пропсов из Blender |
| Риски | Мир может показаться скучным, поэтому нужна тонировка бумаги по аренам и цветные следы магии. Сходство с Doodle | Всё светится, бой превращается в кашу. Bloom дорогой на слабом GPU. Тёмная картинка плохо читается | Выглядит как «очередная инди-игра на Unity», слабая идентичность. Цвета мира спорят с цветами стихий |
| Сложность | Средняя (переиспользуем схему Doodle) | Средняя | Низкая |

**Отклонено:** акварель (нестабильна во времени при движении камеры и размывает магию); копия Doodle 1:1 (нет своего лица).

**Почему A:** схема проверена в браузере, магия гарантированно читается, пропсы из Blender стилизуются автоматически, стиль запоминается со скриншота.

**Правило трёх слоёв по яркости (для A):**
- **мир** занимает средние тона (25–90 % яркости) и не насыщен;
- **враги** — самое тёмное в кадре: чистая тушь с белым ореолом;
- **магия** — единственная насыщенность и самое яркое.

Если любой объект арены нарушает это правило, это баг.

## 2. Маги-противники от первого лица

**Конструкция «Плащ, маска, руки»** (~2 тыс. треугольников, 2 draw call'а на мага):

| Часть | Из чего | Зачем |
|---|---|---|
| Плащ-колокол | `LatheGeometry` по профилю, подол колышется в вершинном шейдере | Ног нет, поэтому бег изображается наклоном и развевающимся подолом |
| Капюшон | Конус или сфера, внутри тьма | Голова и хит-зона головы |
| Маска | Low-poly из Blender (в прототипе сплюснутая сфера) | Лицо. Прорези глаз светятся цветом стихии **и видны только спереди** |
| Парящие руки | Две «варежки» без предплечий, как у Rayman | Каст и направление прицела |
| Сигил | Плоское кольцо-руна за головой, вращается | Стихию видно с любого ракурса |
| Кромка | Форма подола и наплечники по стихии | Силуэт стихии читается без цвета |
| Клякса-тень | Декаль под магом | Высота в прыжке |

Силуэты по стихиям: у Огня рваный подол «языками» и высокий воротник; у Воды длинный волнистый подол; у Земли короткий тяжёлый плащ, широкие каменные наплечники и низкая посадка; у Воздуха узкий плащ с лентами-шарфами, маг парит на 15 см выше.

Альтернативы: **сфера-дух** дешевле, но безлика и не показывает взгляд (оставим для монстров в коопе); **человечек из трубок** как в Doodle требует анимации ног.

**Анимация без скелета** (пружины, синусы и squash & stretch):

| Состояние | Что видно | Приём |
|---|---|---|
| Стоит | Парит ±3 см с частотой 0,7 Гц, руки дрейфуют | Синус плюс шум, фаза своя у каждого |
| Бег / стрейф | Наклон до 12° по скорости, крен 8° при стрейфе, подол тянется назад | Пружина от вектора скорости, вершины подола смещаются против скорости |
| Прыжок | Сжатие 0,85 → растяжение 1,15 → сжатие при посадке | Масштаб по Y с сохранением объёма |
| Каст: замах | Руки уходят назад, тело сжимается, глаза разгораются | Позы рук плюс пружины, длительность = время телеграфа из карточки |
| Каст: выпуск | Руки выбрасываются к цели, тело вытягивается, сигил вспыхивает | Пружина с перелётом |
| Удержание | Руки вместе, подол поднимает «ветер» стихии | Смещение вершин |
| Урон | Инверсия цвета на 60 мс, толчок от точки удара, брызги туши | Флаг попадания с направлением |
| Мало HP | Маска в трещинах, подол осыпается | `discard` по шуму с порогом от HP |
| Смерть | Плащ оседает за 0,3 с, маска падает и **смешно катится**, клякса туши на полу, цветной «дух» уходит вверх | Маска становится физическим обломком, как в Doodle |
| Появление | Клякса на полу «вырастает» в мага | Смерть наоборот, 0,5 с |

**Читаемость с одного взгляда:**
- **кто враг:** по яркости и маркеру (см. раздел 4), не по оттенку;
- **какая стихия:** цвет глаз и сигила, частицы у рук, силуэт кромки;
- **куда смотрит:** маска и руки повёрнуты по yaw/pitch. **Видишь светящиеся глаза — он смотрит на тебя.** Каст летит из ладони по линии взгляда.

Хитбокс (капсула плюс сфера капюшона) должен совпадать с силуэтом плаща. Это вопрос честности.

## 3. Руки от первого лица

| Вариант | Как сделано | Этап |
|---|---|---|
| Варежки из примитивов | Сфера-ладонь, 4 капсулы-пальца, конус рукава. Позы задаются поворотами в коде | **прототип** |
| Low-poly руки из Blender | 1,5–3 тыс. треугольников на пару, 6 поз как **shape keys** (morph targets), скелета нет. Смешиваем веса | **MVP** |
| Руки из света | Только светящийся контур и частицы. Фишка Воздуха | потом |

Позы: открытая ладонь, кулак, когти, два пальца, «чаша», расслабленная. Руки рисуются отдельным проходом со своим FOV 60°, поэтому не протыкают стены. Контур у них в 1,5 раза толще. **Руны на тыльной стороне ладоней** светятся, когда Q/E готовы. Это диегетическая перезарядка, она дублирует HUD.

| Стихия | Характер (стиль «Аватара») | Основная атака | Жест способностей | Замах |
|---|---|---|---|---|
| Огонь | Резкие удары (северный шаолинь) | Попеременные удары, огонь срывается с костяшек | Толчок двумя ладонями, взмах-веер | 60–100 мс |
| Вода | Круги (тайцзи) | Рука чертит дугу, капля слетает с пальцев | Обе руки описывают круг, жест «потянуть к себе» | 120–180 мс, слитно |
| Земля | Тяжесть (хунгар) | Ладонь снизу вверх, камень вырывается из пола | Удар ладонями вниз (камера «ныряет»), подъём стены двумя руками | 180–250 мс + тряска |
| Воздух | Вращение (багуачжан) | Быстрый толчок ладонью, рука уходит за кадр | Вращение кисти, руки разводятся в стороны | 50–90 мс |

## 4. Цвет и форма стихий

Беру четыре стихии «Аватара» и два резервных слота. Финальный список за ролевым дизайнером.

| Стихия | Цвет | Природа света | Частицы | Движение | Силуэт эффектов | Глиф |
|---|---|---|---|---|---|---|
| Огонь | Оранжевый `#FF7A1A`, ядро `#FFE2A0` | Яркое свечение | Капли-языки, искры | Вверх, рвано, мерцает | Веер, конус, расширяется вверх | ▲ |
| Вода | Лазурь `#2F9BFF`, пена `#CFF3FF` | Умеренное, полупрозрачная | Капли, кольца, ленты | Плавные дуги, падает вниз | Дуги, волны, горизонталь | ≈ |
| Земля | Нефрит `#3DBE7A` только в трещинах | **Не светится**: тёмный камень и светящиеся трещины | Угловатые осколки, пыль | Тяжело, по баллистике, удар-стоп | Стены, столбы, вертикальные блоки | ■ |
| Воздух | Бледная лаванда `#D8D0FF` | Самая светлая, без заливки, только штрихи | Полоски, спирали, листья | Быстро, по спирали, без гравитации | Вихри, кольца-толчки | @ |
| Молния (резерв) | Жёлтый `#FFE84A` + белый | Вспышки на 1–3 кадра | Ломаные отрезки | Мгновенно | Зигзаг | ϟ |
| Тень (резерв) | Фиолет `#A55BFF` | Инвертирована: чёрное ядро, цветная кайма | Клочья | Втягивается к центру | Воронки, сферы | ☾ |

**Правило дальтонизма:** любая пара стихий отличается минимум по двум признакам из трёх: оттенок, яркость, форма или движение. Опасная пара — Огонь и Земля при дейтеранопии. Их разводит то, что Земля тёмная, не светится и угловатая, а Огонь светлый и поднимается вверх. Проверка: эмуляция дальтонизма в Chrome DevTools (Rendering → Emulate vision deficiencies) на каждом скриншоте MVP.

**Команды по яркости и форме, а не по оттенку:**

| | Тело | Маркер | Заклинания |
|---|---|---|---|
| **Чужие** | «Тушь»: чёрный плащ и белый ореол 2 px по маске персонажа | ▼, только когда враг в зоне видимости | С **чёрной каймой** |
| **Свои** | «Бумага»: светлый плащ, тонкий контур, виден сквозь стены | ◯ и ник | С **белой каймой**, на 20 % прозрачнее |
| **Я** | — | — | Без каймы, приглушены у камеры |

Стихия на всех выглядит одинаково (глаза, сигил, частицы). Значит, «чёрная кайма = опасность» работает для любой стихии. В FFA все чужие — «тушь». Опция доступности: цвет ореола врага (белый, жёлтый, пурпурный). Красный в интерфейсе зарезервирован под урон и HP, поэтому Огонь сдвинут к оранжевому.

## 5. Окружение и арены

- **Небо** считается в пост-пассе для пикселей без глубины: градиент туши, два слоя облаков-мазков из шума, диск луны с ореолом. Геометрии ноль.
- **Даль:** 3–4 слоя горных силуэтов, дальние растворяются в бумаге («пустота» сумиэ). Дёшево и закрывает край карты.
- **Свет:** один направленный, полуламберт, 3 тона размывки. **Карт теней нет**, под персонажами кляксы.
- **Туман:** растворение к цвету бумаги по глубине плюс низовой туман в низинах.
- **Материалы-кисти** (8–12 штук, узор привязан к миру, как штриховка в Doodle): камень — сухая кисть, дерево — волокна вдоль оси, черепица — ряды дуг, вода — анимированная рябь, листва — пятна, ткань без узора, но колышется.

| Арена | Бумага | Витрина для | Этап |
|---|---|---|---|
| Горный монастырь | Тёплая, сепия | Всех стихий | **прототип** |
| Затопленный храм | Холодная серо-голубая | Воды, молнии | MVP |
| Пепельная кузня | Ночь: тёмная бумага, светлые линии (палитра инвертирована) | Огня | MVP |

**Магия и мир:**

| Стихия | Свет | След (пул декалей) | Прочее |
|---|---|---|---|
| Огонь | Тёплые пятна на стенах: до 8 «магических источников» в пост-пассе | Подпалина с тлеющим краем, 15 с | Фонари и знамёна горят, дым из серых мазков |
| Вода | Слабый голубой блик | Лужа с кольцами ряби, 20 с | Лужа + молния = искры (если ролевой дизайнер введёт) |
| Земля | — | Трещины, осколки, валуны-укрытия | Пыль, тряска |
| Воздух | — | **Сдувает чужие следы** и листья | Развевает ткани арены |

К концу раунда арена расписана следами боя. **Потом:** финальный кадр матча как открытка «картина боя», чтобы делиться с друзьями.

## 6. Задачи владельцу в Blender

| # | Задача | Сложность | Треуг. | Этап |
|---|---|---|---|---|
| 1 | Камни и валуны, 6–8 штук | Очень легко | 50–300 | прототип |
| 2 | Пропсы: фонари, колонны, ворота, мостики, ступени, ограды | Легко | 100–800 | MVP |
| 3 | Маски стихий, 4–6 штук | Легко | 200–600 | MVP |
| 4 | Дальние хребты, слои | Легко | ≤ 2000 на слой | MVP |
| 5 | Стилизованные деревья и бамбук (кроны-капли) | Легко–средне | 300–1200 | MVP |
| 6 | Наплечники и капюшоны по стихиям | Средне | 300–1000 | MVP |
| 7 | Руки с 6 shape keys | Средне | 1500–3000 на пару | MVP |
| 8 | Арена целиком, коллизии — боксы `COL_*` | Средне | ≤ 60 тыс. на арену | MVP, по желанию |
| 9 | Крупные «герои» арены: храм, статуя | Средне–сложно | ≤ 10 тыс. | потом |
| ✗ | Скелет, скиннинг, анимации | **не делаем** | — | — |

**Правила экспорта:**
- glTF 2.0 Binary (`.glb`), 1 единица = 1 м, Apply Transforms, origin в основании объекта, модификаторы применены.
- **Без текстур и UV.** Материал задаётся только именем: `ink_stone`, `ink_wood`, `paper_cloth`, `emit_rune`. Загрузчик подменяет его на наш шейдер. Не больше 3 материалов на объект.
- **Контуры рисуются нормалями.** Острое ребро (Mark Sharp, Auto Smooth 30°) даёт линию, гладкое не даёт. Это главный художественный инструмент владельца.
- Вершинные цвета используются как маски: R — свечение рун, G — ручное затемнение (AO).
- Shape keys экспортируются как morph targets.
- Сжатие через gltfpack (meshopt): ≤ 200 КБ на пропс, ≤ 2 МБ на всё.

## 7. UI и HUD: «кисть и печать»

- **Палитра:** бумага, тушь и одна краска интерфейса, киноварь `#C8322A`, только для HP и опасности. Цвета стихий встречаются лишь в иконках способностей.
- **Q/E/C:** глиф способности тушью внутри **энсо** (круг одним мазком). Во время перезарядки энсо дорисовывается по кругу (SVG `stroke-dashoffset`). Когда способность готова, круг замыкается, заливается цветом стихии и брызгает каплей. Заряды показаны каплями под иконкой, клавиша подписана мелко в углу. **Прототип:** круг и цифра. **MVP:** энсо.
- **Ульт X** (если будет): квадратная печать, которая заполняется снизу, как впитывающаяся тушь.
- **HP:** мазок кисти. Потерянное здоровье «высыхает» светлым следом за 0,5 с.
- **Прицел по стихии:** у Огня три точки треугольником, у Воды дуга, у Земли уголки, у Воздуха точка с завитком. Есть опция «просто точка».
- **Лента убийств:** оттиск печати с глифом стихии жертвы.
- **Выбор стихии:** свитки в ряд. При наведении свиток заливается цветом, показывается живое 3D-превью мага и рук (бесплатно, всё процедурное), три иконки и ярлык роли. Подтверждение — удар печатью «Выбрано». Видны выборы союзников.
- **Шрифты** (Google Fonts, кириллица, OFL, своя раздача woff2 с подмножеством): заголовки — **Cormorant SC** или Forum; интерфейс и цифры — **Manrope** с `tabular-nums`; рукописные подписи — **Marck Script**.
- **Техника:** DOM поверх canvas, как в Doodle; анимируем только `transform` и `opacity`, SVG-фильтры не анимируем.

## 8. Производительность

Цель: **60 fps на Intel UHD 620 / Iris Xe при 1080p**, минимум 45.

| Параметр | Низкое → Высокое |
|---|---|
| Разрешение рендера | 0,67 → 1,0, динамическое; pixelRatio ≤ 1 → 1,5 |
| Draw calls | ≤ 120. Статика сливается по материалу, маг — 2 вызова |
| Треугольники в кадре | ≤ 150 тыс. → 300 тыс. |
| Пост-пасс | Один, ≤ 13 выборок текстуры |
| Свечение магии | Спрайты-ореолы без bloom → HDR-буфер в ½ разрешения + 2 прохода размытия в ¼ |
| Частицы | 600 → 2000. GPU-инстансинг, движение считается в вершинном шейдере (без CPU) |
| Магический свет | 4 → 8 источников |
| Декали-следы | 48 → 128 |
| Тени / AA | Нет / нет → FXAA |
| Загрузка | ≤ 3 МБ: код, glb и шрифты |

Главный враг встроенной графики — **overdraw**: частиц меньше, но крупнее и с фигурной альфой, аддитив без сортировки, спрайт не больше 15 % экрана. Пресет выбирается автоматически по времени кадра за первые 5 секунд.

## Что мне нужно от других ролей

- **Разработчик:** решение по WebGL2 и MRT для G-buffer и HDR-буфера магии; загрузчик glb с подменой материалов по имени; пул декалей и GPU-частиц; пресеты качества и динамическое разрешение; сетевые флаги для анимации (фаза каста, id способности, направление попадания); dev-страница «превью стиля» для моделей владельца.
- **Геймдизайнер:** командный режим или FFA (от этого зависят правила маркеров); число игроков (бюджет); размеры хитбоксов под силуэт плаща; длительности телеграфов.
- **Гейм-эффектник:** общая система частиц. Я отвечаю за цвет, форму и силуэт, он за тайминги и «сок». Нужно согласовать бюджет: ≤ 150 живых частиц на каст.
- **Ролевой дизайнер:** финальный список стихий; тип каждой способности (снаряд, луч, зона, стена, рывок) для силуэтов; взаимодействия стихий, у которых есть визуальное состояние.
- **Левел-дизайнер:** правило фона (за зонами боя нет тёмных масс, иначе враги-«тушь» теряются); теги материалов поверхностей; ровные полы под следы; слои дали.
- **Адвокат игрока:** тест «5 секунд по скриншоту» (кто враг, какая стихия, куда смотрит), в том числе в режиме эмуляции дальтонизма.

## Вопросы владельцу

**1. Визуальное направление?**
- A — «Тушь и свет», монохромный мир и цветная магия;
