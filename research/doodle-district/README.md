# Doodle District: разбор устройства игры

Источник: https://doodleshooter.vercel.app/ (бандл `game.7LCERBLR.js`, сборка от 15.10.2026).
Отформатированный исходник лежит в [source/game.pretty.js](source/game.pretty.js); номера строк ниже указаны по нему.

> Жанр: браузерный FPS «на тетрадном листе». Соло — волны врагов с боссами, онлайн — free-for-all до 10 игроков.
> Много движения: грэппл, двойной прыжок, прыжок от стены, слайд, рывок. Катаной можно отбивать пули обратно во врагов.

## 1. Стек и поставка

| Что | Как сделано |
|---|---|
| Язык | Чистый JS (ES-модули), без фреймворков и без TypeScript в рантайме |
| 3D | **Three.js 0.170** через `<script type="importmap">` с jsDelivr. В бандл не входит. Из аддонов используется только `BufferGeometryUtils.mergeGeometries` |
| Сеть | **PeerJS 1.5.4** (WebRTC) глобальным `<script>`. Сигналинг через бесплатный облачный сервер PeerJS, STUN Google и Cloudflare, публичный TURN `openrelay.metered.ca` |
| Сборка | Один файл `game.[hash].js` (~300 КБ минифицированного кода) и `style.[hash].css` (22 КБ). Хэш из 8 заглавных символов base32 похож на формат **esbuild** (это предположение) |
| Хостинг | Статика на Vercel плюс Vercel Web Analytics. **Своего бэкенда нет** |
| Ассеты | **Ноль файлов.** Нет текстур, моделей и аудио. Геометрия, звук и музыка генерируются кодом. Извне грузятся только шрифты Google Fonts: Patrick Hand и Caveat |

`index.html` содержит только `<canvas id="c">`, `<div id="hud">`, importmap и два скрипта.

## 3. Рендеринг: откуда берётся «тетрадный» вид (самое интересное)

Это **не** текстуры и не стандартные материалы Three.js. Используется **отложенный стилизатор в два прохода**.

### Проход 1: сцена пишет G-buffer вместо цвета ([строки 1–60](source/game.pretty.js:1))
Все меши используют один `ShaderMaterial` из `gt({ink, fill, shadeScale, shadeBias})`. Рендер идёт в `WebGLRenderTarget` (RGBA HalfFloat + `DepthTexture` Float). В каналы пишется:
- **R** — освещённость `dot(N, L)*0.5+0.5` (полуламберт). `-1` означает «залить сплошным цветом» (`fill`);
- **G** — **номер чернил** 0…5 из палитры `BLUE, RED, BLACK, ORANGE, GREEN, PINK`;
- **BA** — нормаль в view-space (xy).

Для `InstancedMesh` номер чернил и `fill` передаются через `instanceColor`, то есть у каждого инстанса свой цвет без лишних материалов.

### Проход 2: полноэкранный шейдер превращает буфер в рисунок ([строки 63–231](source/game.pretty.js:63))
1. **Бумага.** Базовый цвет плюс зерно (value noise), голубые линейки и красное поле на 7 % ширины. Для Jungle включён режим миллиметровки (`style.lines = 1`) и своя палитра чернил.
2. **Контуры.** Edge detection по **лапласиану обратной глубины (1/d)**. Для любой плоскости 1/d аффинна по экрану, поэтому пол под скользящим углом не даёт ложных линий, а дальние контуры остаются чёткими. Сюда же добавляются разрывы нормалей. Цвет контура берётся у ближайшего к камере соседнего пикселя.
3. **Штриховка.** Три семейства полос под разными углами включаются порогами освещённости 0.64 / 0.42 / 0.24 / 0.12, как при ручной штриховке карандашом. Штрихи **привязаны к миру**: позиция восстанавливается из глубины через `uInvProj/uInvView`, проецируется на плоскость, к которой ближе нормаль, а шаг квантуется степенями двойки по дистанции (LOD). Так штриховка не «плывёт» при движении и не даёт муар. Для оружия в руках (d < 2) штриховка экранная.
4. **Дрожание руки.** UV сдвигаются низкочастотным шумом.
5. **Затухание** штриховки и контуров с расстоянием.
6. **Геймплейные эффекты в том же шейдере:** красная «каракулевая» виньетка при уроне, пульсация при низком HP, белая вспышка, обесцвечивание в slow-mo.

Прочее: `antialias: false`, `pixelRatio ≤ 1.5`, FOV 80–82, near 0.08, far 420. Статическая геометрия уровня **сливается по цвету чернил** (`mergeGeometries`): одна корзина на пару «чернила × заливка», то есть не больше 12 мешей на всю статику, с `matrixAutoUpdate = false`. Анимированные объекты и пропсы остаются отдельными мешами.

> Как повторить: один G-buffer-материал на всё, палитра из 6 цветов, один post-pass. Этого достаточно для узнаваемого стиля.

## 4. Физика и коллизии — своя, без движка ([331–592](source/game.pretty.js:331))

- Мир — это **список AABB-боксов** в равномерной 2D-сетке (ячейка 8 м по XZ). Флаги на боксе: `noNav`, `noShoot` (пули пролетают сквозь, например перила), `noGrapple`, `breakable`.
- Тело персонажа — AABB (`halfW`, `height`, `pos`, `vel`). `moveBody` делит шаг на подшаги по скорости (до 10, против туннелирования) и разрешает столкновения **поосно**: X, потом Z, потом Y. Есть **step-up** на ступеньки (0.55 м) и прилипание к земле при сходе с уступа. Наружу выставлены `onGround`, `hitWall`, `wallNormal`, `landVel` — из них потом строятся wall jump и mantle.
- `raycast` — slab-тест по **всем** боксам перебором (сетка не используется). Для пары сотен боксов этого хватает.
- В врагов стреляют по **хит-сферам на костях** (голова 0.3, торс 0.33, руки, ноги, щит). Пересечение луч-сфера, хедшот = попадание в часть `head`.

## 5. Навигация и ИИ врагов

### Навигационная сетка ([6690–6855](source/game.pretty.js:6690))
- Строится при загрузке уровня по сетке 1×1 м. В каждой клетке вертикальный запрос даёт верхние грани коллайдеров, и каждая проходимая поверхность с просветом 1.85 м становится узлом. Узлы на разных этажах — это разные узлы.
- Связи с 8 соседями: подъём до 1.35 м, спуск до 8 м, проверка срезания углов и просвета. Подъём стоит дороже.
- **A\*** на бинарной куче. Массивы `g/from` переиспользуются через generation-счётчик, без аллокаций. Лимит 40k раскрытий. Если цель недостижима, возвращается частичный путь до ближайшего узла.

### Поведение ([2296–3542](source/game.pretty.js:2296), `_think` на [2962](source/game.pretty.js:2962))
Конечный автомат `spawn → hunt → stunned → dead`, поведение зависит от типа:

| Тип | HP | Поведение |
|---|---|---|
| GRUNT | 100 | Винтовка, очереди по 3, держит дистанцию 7–16 м, стрейфит |
| RUSHER | 70 | Клинок: выпад с телеграфом, потом отскок. Блок катаной оглушает его |
| INK BOMB | 26 | Бежит к игроку, поджигает фитиль за 1.05 с, взрывается и ранит врагов тоже |
| SNIPER | 60 | Стационарный, целится 1.7 с с видимым лазером, 22 урона |
| PAPER WASP | 40 | Летает по орбите и пикирует |
| HEAVY | 320 | Дробовик, 7 дробин |
| SHIELDBEARER | 150 | Щит выдерживает 2 удара катаной или взрыва, потом разлетается |
| Боссы | 2600–3400 | THE DOODLER, THE ERASER, THE INKBLOT — каждый со своим набором атак |

Приёмы, которые делают ИИ «живым» почти даром:
- **Точки подхода по золотому углу** (`appAng += 2.39996` на каждого заспавненного). Враги окружают игрока, а не собираются в кучу.
- Проверка линии видимости раз в 0.12–0.22 с, перепрокладка пути раз в 0.8–1.4 с.
- Расталкивание врагов друг от друга (separation) раз в 50 мс.
- Застрял у стены 0.9 с — враг прыгает.
- Враги стреляют **медленными видимыми снарядами** (пул `InstancedMesh` на 240 штук). Поэтому их можно отбить катаной.

### Модели и расчленёнка ([1814–2131](source/game.pretty.js:1814))
Все враги — процедурные «человечки» из сфер, кубов и `TubeGeometry` по кривой Безье (кривые ручки-ножки). У каждого типа своя шапка: кепка, бандана, шлем, капюшон, корона. Глаза при смерти меняются на крестики. Части тела отрываются: узел переподвешивается в сцену и становится обломком с физикой и кровью. Труп падает с анимацией, под ним появляется лужа. Кляксы — 8 процедурных форм `ShapeGeometry`.

## 6. Игрок, оружие, «сок»

**Движение** ([8291](source/game.pretty.js:8291), `update` на [8583](source/game.pretty.js:8583)): спринт, присед и слайд, двойной прыжок, прыжок от стены, подтягивание на уступ (mantle), рывок в воздухе, coyote time и буфер прыжка. **Грэппл**: качание на верёвке, подтягивание, прыжок для запуска, расход стамины. Если зацепить врага, его притягивает и оглушает. HP 120, регенерация через 4.5 с по 11 HP/с.

**Оружие** (таблица `zr`, [7620](source/game.pretty.js:7620)) у игрока **hitscan**:

| | Магазин | Урон | Хедшот | Особое |
|---|---|---|---|---|
| Rifle | 35 | 24 | ×2.6 | автомат, 11 выстр/с |
| Shotgun | 6 | 10 × 19 | ×1.8 | урон падает с дистанцией, перезарядка по патрону |
| Sniper | 5 | 150 | ×3 | прицел, FOV 20 |
| Katana | ∞ | 75 | — | комбо. Блок отражает пули: обычно ×2.2 урона, при идеальном парировании ×3.5 и пуля летит в стрелявшего |

Вьюмодели собраны из примитивов, висят на `camera.rig` и анимируются пружинами.

**Ощущение от попаданий:**
- Критически демпфированные пружины (`ss`/`Ds`) на отдачу, FOV-kick, проседание камеры при приземлении.
- **Hitstop**: время замедляется на 0.025–0.05 с при убийстве.
- **Focus**: 3 убийства катаной подряд включают slow-mo ×0.26, а «dash-slash» цепляет и казнит цели по цепочке.
- Вибрация геймпада, хитмаркеры, комбо-множитель очков `1 + 0.25·min(combo, 9)`, бонусы за хедшот, убийство в воздухе, отражённую пулю.

## 7. Игровой цикл и режимы ([13243–13371](source/game.pretty.js:13243))

- `requestAnimationFrame` с переменным `dt`, ограниченным 50 мс. Глобальный time-scale (hitstop или Focus) применяется к симуляции, но не к UI.
- **Трюк для онлайна:** `setInterval(250 мс)` продолжает симуляцию без рендера, когда вкладка скрыта и rAF заморожен. Иначе игрок «замёрз» бы для остальных.
- Состояния: `start / play / pause / dying / dead / lobby / over`. Режимы: `solo` и `ffa`.

### Волны (соло) ([11427–11571](source/game.pretty.js:11427))
- Взвешенная случайная очередь. Типы открываются по номеру волны: grunt с 1-й, rusher со 2-й, bomber и sniper с 3-й, flyer с 4-й, heavy с 5-й, shield с 6-й.
- Размер волны `min(5+2n, 32+n)`. Лимит одновременно живых врагов растёт. Интервал спавна `max(0.7, 2.9 − 0.13n)`.
- **Каждая 5-я волна — босс** по кругу Doodler, Eraser, Inkblot. HP босса растёт каждые 15 волн.
- Модификаторы волн: CAFFEINATED (быстрее), HEAVY INK (больнее), SWARM (больше врагов).
- Точка спавна в 14–48 м от игрока, по возможности вне его поля зрения.
- Пауза 8 с между волнами, +40 HP. Чекпоинт каждые 5 волн сохраняется в localStorage.

### FFA (онлайн)
Матч 10 минут или до 20 убийств. Карта загружается в варианте `arena` (больше, 68 м вместо 55). Падение с карты стоит −1 убийство.

## 8. Звук и музыка — полностью синтез ([927–1623](source/game.pretty.js:927))

- Два примитива: `noise({freq, freqEnd, type, q, dur…})` — буфер белого шума через биквадратный фильтр с огибающей, и `tone({freq, freqEnd, type…})` — осциллятор с огибающей. Из них собрано около 60 звуков: выстрелы, перезарядки, парирование, взрывы, шаги, рёв боссов.
- Простая 3D-позиция: затухание `1/(1+0.09·d)` плюс `StereoPanner` по проекции на вектор «вправо» слушателя. На мастере стоит компрессор.
- **Музыка** — чиптюн-секвенсор: 156 BPM, шестнадцатые, планирование нот на 0.7 с вперёд из `setInterval(100 мс)` (классическая схема «lookahead scheduling»). Секции с разными стилями баса (bounce, drive, sparse, pump), барабаны, арпеджио, эхо. Параметр **intensity** зависит от числа врагов. Для Mexico отдельная мариачи-тема.

## 9. Ввод ([660–922](source/game.pretty.js:660))

Слой действий: клавиши, кнопки мыши и геймпада мапятся в имена действий (`fire`, `grapple`, `dash`…). Есть `pressed/released` через сравнение с прошлым кадром. Pointer Lock включается с `unadjustedMovement`, при отказе — повтор. На геймпаде мёртвая зона 0.14, кривая отклика ^1.8 и ускорение поворота при удержании стика. Режим тачпада: Shift — прицел, двойной W — спринт.

## 10. Мультиплеер без сервера ([9588–10644](source/game.pretty.js:9588), обработчики на [12286](source/game.pretty.js:12286))

**Топология.** Хост — звезда поверх PeerJS DataConnection (надёжный JSON). На том же `RTCPeerConnection` открывается **второй канал `fast`** с `ordered: false, maxRetransmits: 0` для состояния, похоже на UDP. Если удалось, клиенты дополнительно соединяются напрямую друг с другом (меш). Иначе хост ретранслирует (`relay`/`fwd`).

**Поиск лобби без бэкенда.** Используются заранее известные PeerJS-ID:
- публичные лобби занимают `doodledistrict-PUB0 … PUB23` (плюс суффиксы `-1..-3`);
- Quick Play стучится во все ~96 ID пачками по 24 штуки каждые 220 мс, собирает ответы `welcome` (игроки, карта, идёт ли матч), меряет RTT и выбирает самое заполненное лобби;
- приватное лобби — 5-символьный код (алфавит без 0/O/1/I), ID `doodledistrict-КОД`.

**Протокол.** `{t, d, s(seq), to, relay|fwd}`. Состояние игрока `ps` отправляется **20 раз в секунду** компактным массивом `[x,y,z,yaw,pitch,weapon,flags(13 бит),hp,vx,vy,vz,(hook xyz)]`. Выстрелы уходят пачкой точек трассеров. По seq отбрасываются устаревшие пакеты, пришедшие не по порядку.

**Удалённые игроки.** Snapshot-интерполяция с задержкой 80 мс, экстраполяция по скорости до 0.35 с. Телепорт, если ошибка больше 6 м.

**Авторитет: «прав стреляющий».** Попадание считает атакующий и шлёт `pdmg` жертве. Жертва применяет урон после проверок, сама объявляет смерть через `pdead` с указанием убийцы. Хост ведёт таблицу счёта, часы матча и пикапы.

**Античит (лёгкий):**
- каждое сообщение проходит схемную валидацию (`Uo`);
- потолок урона на одно попадание для каждого оружия (`Us`);
- лимиты частоты стрельбы и гранат;
- не больше 560 урона в секунду от одного игрока;
- проверка «невозможного здоровья»;
- нарушителей блокирует хост и рассылает `peerblocked`;
- проверка версии протокола `v = 4`.

**Миграция хоста.** Есть заранее известный порядок преемников. Следующий в очереди пересоздаёт лобби под ID `КОД-<gen>`, остальные переподключаются, перебирая gen. Позже исходный код лобби забирается обратно как alias. На всё отводится 45 секунд.

Ещё: кик за бездействие, автопереподключение к сигналингу. **Рудимент:** в `mi` есть `snapshot/applySnapshot/mirror` для синхронизации врагов. Это код кооператива, который сейчас нигде не вызывается.

## 11. Уровни — код вместо редактора ([3555–3796](source/game.pretty.js:3555))

Уровни **написаны вручную** на маленьком DSL из `wr()`:
`box, slab, wallX/wallZ` (стена с проёмами, проёмы вычитаются как интервалы), `stairs, rail, cyl, sphere, ring`, точки `spawn / sniper / pickup`, анимированные цели для грэппла (`planes`, `birds` летают по кругу), `prop` (физические предметы), `breakable` (разрушаемые объекты).
Каждый вызов одновременно добавляет геометрию в корзину своего цвета чернил и коллайдер в физический мир. В `finish()` корзины сливаются в меши.

Карты: **District** (город, крыши, пожарные лестницы, купол-«клетка»), **Jungle** (джунгли и храм, миллиметровка), **Mexico** (тестовая, только в dev-режиме).

## 13. Выводы: что взять себе и где слабые места

**Что стоит перенять:**
1. G-buffer с номерами чернил и один post-pass. Мощная стилизация почти бесплатно и без единой текстуры.
2. Слияние статики по материалу. Вся неподвижная часть города укладывается в дюжину draw call'ов.
3. Свои AABB-коллизии и навсетка на сетке вместо физического движка. Для «коробочного» мира этого хватает с запасом.
4. Процедурный звук на двух функциях `noise/tone`. Ноль ассетов, мгновенная загрузка.
5. Набор приёмов для ощущения от попаданий: пружины, hitstop, slow-mo, вибрация, хитмаркеры, комбо.
6. P2P-лобби на известных PeerJS-ID. Мультиплеер без единого сервера.

**Слабые места:**
- `world.raycast` перебирает все боксы, сетка не используется. Масштабируется плохо.
- Урон считает клиент, и лимиты только ограничивают читера, а не исключают его.
- Сеть зависит от бесплатных сервисов: облако PeerJS и публичный openrelay TURN. Если они упадут, онлайн перестанет работать.
- Весь проект — один файл на 13k строк с общим мутируемым контекстом. Расширять тяжело.
